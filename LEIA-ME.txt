# Estoque de Aviamentos — pacote para Render + PostgreSQL

## Estrutura
- `server.js`: API Express e integração PostgreSQL.
- `package.json`: dependências e comando `npm start`.
- `public/index.html`: interface atual com sincronização via `/api/state`.

## Configuração no Render
No Web Service:
- Build Command: `npm install`
- Start Command: `npm start`
- Root Directory: deixe vazio se `server.js` e `package.json` estiverem na raiz do repositório.

Em Environment, configure `DATABASE_URL` usando a **Internal Database URL** do PostgreSQL do Render, se o serviço e o banco estiverem na mesma região. Não publique nem compartilhe essa URL: ela contém credenciais.

## Instalação pelo GitHub no celular
1. Baixe e extraia o ZIP.
2. No repositório, mantenha `server.js` e `package.json` na raiz.
3. Crie a pasta `public` e coloque `index.html` dentro dela. Se o seu projeto atual já usa `index.html` na raiz, o servidor também tenta servir essa versão como fallback.
4. Faça commit dos arquivos e aguarde o deploy do Render.

## Testes após o deploy
- `/api/health`: deve retornar `ok: true` e `databaseConfigured: true`.
- `/api/db-status`: deve retornar `connected: true`.
- `/api/state`: na primeira execução, deve retornar `{"empty":true,"state":null}`; após salvar dados, retorna `empty:false` e o estado.

## Observações importantes
- A API usa uma tabela nova chamada `estoque_app_state_store` para evitar o conflito de coluna `state` na tabela antiga. Ela não apaga nem altera tabelas antigas.
- O `index.html` guarda cache local e tenta sincronizar o estado com a API quando o servidor estiver conectado.
- Faça backup do repositório antes de substituir arquivos.
- Não envie comandos de exclusão nem apague o banco.
