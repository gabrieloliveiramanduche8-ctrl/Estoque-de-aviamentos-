# Arquivos corrigidos — Estoque de Aviamentos

## Arquivos incluídos
- `package.json`: define as dependências e o comando `npm start`.
- `server.js`: servidor Express, publicação do `index.html`, rota de saúde e teste opcional do PostgreSQL.
- `.env.example`: exemplo sem credenciais.

## Como instalar no GitHub pelo celular
1. Abra o repositório correto e a branch `main`.
2. Abra `package.json` e substitua o conteúdo pelo arquivo deste pacote; salve/commit.
3. Abra `server.js` e substitua o conteúdo pelo arquivo deste pacote; salve/commit.
4. Não substitua `index.html` nem apague a pasta `public`.
5. No Render Web Service, use:
   - Build Command: `npm install`
   - Start Command: `npm start`
   - Root Directory: deixe vazio se os arquivos estiverem na raiz.
6. Faça o deploy.

## PostgreSQL
O servidor inicia mesmo que `DATABASE_URL` ainda não esteja configurada. Para conectar o banco, crie/seleciona um PostgreSQL no Render e adicione `DATABASE_URL` em Environment Variables com a URL fornecida pelo Render. Não publique essa URL no GitHub nem a envie em mensagens.

## Testes depois do deploy
- `/api/health` deve responder com JSON e `ok: true`.
- `/api/db-status` informa se a variável do banco está configurada e se a conexão funciona.

Importante: estes arquivos preparam o servidor e a conexão de diagnóstico. Eles não implementam, por si só, operações de estoque nem criam tabelas de negócio no banco. Isso depende do código e dos requisitos existentes do sistema.
